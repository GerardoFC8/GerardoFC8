### Featured projects

<div align="center">

![Featured projects](https://raw.githubusercontent.com/GerardoFC8/GerardoFC8/main/metrics.plugin.repositories.svg)

</div>

- **[Apostrophe for Windows](https://github.com/GerardoFC8/apostrophe-for-windows)** · Rust, Tauri 2
  Native Markdown editor, a port of GNOME's Apostrophe. Exports to PDF, DOCX, EPUB and LaTeX with nothing else to install. Available on winget: `winget install GerardoFC8.ApostropheForWindows`
- **[achica](https://github.com/GerardoFC8/achica)** · TypeScript, WebAssembly
  Batch image compressor that runs 100% in the browser. CI verifies in Chromium and Firefox that not a single byte leaves the device. Live at [achica.gfcode.dev](https://achica.gfcode.dev)
- **[claude-subagent-statusline](https://github.com/GerardoFC8/claude-subagent-statusline)** · Node.js
  Claude Code plugin with a live statusline: model, cost, context, sub-agents and rate limits. Installable from its own marketplace.
- **[Barra](https://github.com/GerardoFC8/windows-media-widget)** · Tauri, Rust
  Media control widget for Windows inspired by niri. A 9 MB executable, no install needed, with native acrylic blur.
