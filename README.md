### Proyectos destacados

<div align="center">

![Proyectos destacados](https://raw.githubusercontent.com/GerardoFC8/GerardoFC8/main/metrics.plugin.repositories.svg)

</div>

- **[Apostrophe para Windows](https://github.com/GerardoFC8/apostrophe-for-windows)** · Rust, Tauri 2
  Editor de Markdown nativo, port del Apostrophe de GNOME. Exporta a PDF, DOCX, EPUB y LaTeX sin instalar nada aparte. Publicado en winget: `winget install GerardoFC8.ApostropheForWindows`
- **[achica](https://github.com/GerardoFC8/achica)** · TypeScript, WebAssembly
  Compresor de imágenes por lotes que corre 100% en el navegador. El CI verifica en Chromium y Firefox que ningún byte sale del dispositivo. En producción: [achica.gfcode.dev](https://achica.gfcode.dev)
- **[claude-subagent-statusline](https://github.com/GerardoFC8/claude-subagent-statusline)** · Node.js
  Plugin de Claude Code con statusline en vivo: modelo, costo, contexto, sub-agentes y rate limits. Instalable desde su propio marketplace.
- **[Barra](https://github.com/GerardoFC8/windows-media-widget)** · Tauri, Rust
  Widget de control multimedia para Windows inspirado en niri. Ejecutable de 9 MB, sin instalación, con blur acrílico nativo.
